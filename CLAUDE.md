# CLAUDE.md — kgsm-api

`kgsm-api` is the per-node KGSM Control Panel API: the aggregator the React SPA and other surfaces talk
to. One node, one API; it aggregates only its own node's engine and leaves. What it owns, who it
depends on and the contracts it takes part in: `../kgsm-docs/components/kgsm-api.md`. The live project is
`src/Api/`; `legacy/` is a scrapped attempt that fabricated metrics, kept for harvest only and never a
design reference.

It signs nobody in: sessions are minted by the cluster's auth anchor and verified here, and what a
caller may do is evaluated per action from this node's replica of the cluster's authority. Auth is ON by
default; `Api__AuthDisabled=true` is the loudly-logged dev escape hatch (a synthetic Owner). Detail:
`src/Api/Services/Auth/CLAUDE.md`.

## Configuration

`src/Api/kgsm-api.settings.json` declares the whole configurable surface under one `Api` section that
`ApiSettings` binds 1:1; `ApiOptions.FromSettings` is the one place any of it is interpreted, and nothing
reads configuration by string key. An environment variable overrides one key by spelling its path with
`__` (`Api__DomainPollMs`), and env wins. A variable naming an undeclared key binds to nothing, and the
build fails when the settings file and `ApiSettings` disagree. Boolean knobs take `true`/`false` only.

`deploy/kgsm-api.leaf.json` and `deploy/kgsm-api.leaf.actions.json` are generated by
`TheKrystalShip.KGSM.ComponentConfig` on every build: edit `ApiSettings` (`[ConfigField]`, `<panel>` doc
tags) and `src/Api/ApiActionDeclarations.cs`, never the JSON, and commit what the build produces. A
settings key nothing describes fails the build; `AllowedHosts` is the declared exemption. This API's
descriptor says `readOnly`: applying a change here means restarting the process serving the request.
Format: `../kgsm-docs/reference/leaf-config-descriptor.md`.

## The stack: JIT, MVC controllers, EF Core (SQLite)

Not Native AOT, and not to be proposed for consistency: controllers and EF Core are AOT-incompatible, and
the API is not embedded in an AOT host. `kgsm-lib` stays AOT-safe and is consumed unchanged. The shape is
`Program` + `Startup` (generic host, `UseStartup<Startup>`), not top-level statements.

## Invariants

1. **Never fabricate a metric, status or alert.** Measured, or explicitly `null`/unknown (ADR 0020).
2. **Metric-presence is not status.** Run-state comes from kgsm-lib's façade (which can itself be
   unknown), metrics from the monitor; join them, never infer one from the other.
3. **Freeze contracts from the frontend spec, don't invent them.** Where a spec shape is not honestly
   sourceable, the DTO omits it by negotiated divergence (`cpuPctCore`, `memBytes`, nullable `io*`);
   record every frozen shape in `PLAN.md §6`.
4. **Additive-only within `/api/v1`.** Grow into reserved fields, never break.
5. **Engine and watchdog only via `kgsm-lib`.** Never shell `kgsm.sh` or open the watchdog socket
   (ADR 0017). A missing kgsm-lib is a surfaced misconfiguration (empty `/servers`, one log line), not a
   capability. A missing or down leaf removes only its capability, never a 500.
6. **Persistence is downstream of the stateless engine.** The API stores only its own operational
   metadata (the audit log's local rows, the ended-session list) via EF; the domain is live-scraped.
   The audit is event-sourced and single-writer: never write a row when issuing a command, and never add
   a second writer for an action a producer already emits (`src/Api/Services/Audit/CLAUDE.md`).

## Conventions

- JSON is camelCase with ISO-8601 UTC `Z` timestamps, configured once in `src/Api.Contracts/ApiJson.cs`.
- Every non-2xx is the `{ "error": { "code", "message", "details?" } }` envelope, via
  `ApiExceptionHandler` (500s) and `UseStatusCodePages` (404, 401, 403). `/health` is ops, not a frontend
  contract.
- Namespaces are `TheKrystalShip.Api.*`. Logging follows `../kgsm-docs/reference/logging-convention.md`;
  the notification-webhook `HttpClient` keeps `.RemoveAllLoggers()` (Startup), which is secret redaction.
- Two version axes: the route version (`/api/v1`, `ApiInfo.ApiVersion`) and the build version
  (`<Version>` in `Api.csproj` plus the git SHA stamped by `SetSourceRevisionId`). `README.md`
  §Versioning has the reference.

## Version tracking

`<Version>` in `src/Api/Api.csproj` is the source; `./deploy/version.sh` prints it (`--pkgver` for the
pacman-safe form) and a package never restates it. Bump on a user-facing change (patch for fixes, minor
for features, major for breaking changes) with a `CHANGELOG.md` entry under `## [Unreleased]`. A change
to `Api.Contracts` is a library change: bump, publish, then re-pin the consumers.

## Gotchas

- **EF `EnsureCreated`, not migrations.** It no-ops on an existing DB, so after any entity change delete
  the DB file or the new column or table silently does not exist and queries 500 at runtime. Do not add
  `Migrations/` without re-deciding this.
- **`SuppressMapClientErrors=true`** (Startup) sends result-based 4xx through `UseStatusCodePages` into
  the envelope; a model-binding `400` is covered by the `InvalidModelStateResponseFactory` in
  `ConfigureApiBehaviorOptions`. Removing either breaks "every non-2xx is the envelope".
